# Neon Nomad

Un jeu d'arcade minimaliste en HTML5/Canvas avec support joystick pour mobile.

## Jouer

[Jouer en ligne](https://fl3o.github.io/My-First-Game/)

## Contrôles

- **PC** : Flèches directionnelles pour bouger, `S` pour sauvegarder
- **Mobile** : Joystick virtuel + bouton `SAVE`

## Fonctionnalités

- Plein écran adaptatif
- Sauvegarde / chargement de partie
- Record persistant (localStorage)
- HUD en jeu
- Support tactile natif

## Déploiement

Ce projet est conçu pour être hébergé directement via **GitHub Pages** :
1. Fork ou clone ce repo
2. Va dans **Settings > Pages**
3. Source : `Deploy from a branch` → sélectionne `main` → `/ (root)`
4. Attends quelques minutes, le jeu sera accessible à `https://<ton-pseudo>.github.io/<nom-du-repo>`
